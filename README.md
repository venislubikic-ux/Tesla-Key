# TK — Tesla Key

Windows-приложение (Python + PySide6) для управления своей Tesla через **официальный Tesla Fleet API**:
вход через сайт Tesla, выбор автомобиля, LOCK / UNLOCK, заряд батареи, состояние, климат.

- Пароль Tesla **никогда** не попадает в TK — вход происходит на `auth.tesla.com` в вашем браузере (OAuth 2.0 + PKCE).
- Токены шифруются (Fernet/AES), ключ шифрования хранится в **Диспетчере учётных данных Windows**.
- Client Secret приложения тоже хранится в Диспетчере учётных данных, а не в файлах.
- Команды подписываются официальным прокси Tesla (`tesla-http-proxy`, Vehicle Command Protocol). Никаких неофициальных обходов.

---

## Как это устроено

```
 TK (PySide6) ──── чтение данных, wake_up ───────────────► Tesla Fleet API (регион EU/NA/CN)
      │                                                         ▲
      └── команды (lock/unlock/климат) ──► tesla-http-proxy ────┘
                                          (localhost:4443, подписывает
                                           команды вашим private-key.pem)
```

С января 2024 года почти все Tesla принимают **только подписанные команды** (исключение — Model S/X до 2021 г.).
Подпись делает официальный прокси Tesla с приватным ключом вашего приложения, а автомобиль проверяет её
по «виртуальному ключу», который вы один раз добавляете в машину через приложение Tesla.
Без прокси TK покажет данные автомобиля, но команды вернут ошибку с подсказкой.

## 1. Установка и запуск

Нужен **Python 3.10+** (python.org, при установке отметьте «Add python.exe to PATH»).

```bat
cd TK
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Или просто дважды щёлкните `run.bat`.

## 2. Сборка TK.exe

```bat
build_exe.bat
```

Результат: `dist\TK.exe` — один файл без консоли. Python на целевом компьютере не нужен.

## 3. Что должен настроить владелец автомобиля (один раз)

Tesla разрешает доступ к Fleet API только зарегистрированным приложениям, поэтому вы регистрируете
**своё собственное** приложение. Это делается один раз, дальше TK работает как обычная программа.

### Шаг 1. Домен для публичного ключа
Tesla требует домен, которым вы владеете: на нём публикуется публичный ключ приложения.
Подойдёт любой хостинг статических файлов с HTTPS (свой сайт, Cloudflare Pages, GitHub Pages и т. п.).

### Шаг 2. Ключи приложения
```bat
python tools\generate_keys.py keys
```
Получите:
- `keys\private-key.pem` — **секрет**, используется только прокси. Никому не передавайте.
- `keys\com.tesla.3p.public-key.pem` — опубликуйте по адресу
  `https://ВАШ-ДОМЕН/.well-known/appspecific/com.tesla.3p.public-key.pem`

### Шаг 3. Приложение на developer.tesla.com
1. Войдите на https://developer.tesla.com и создайте приложение (Create Application).
2. **OAuth Grant Type:** Authorization Code and Machine-to-Machine.
3. **Allowed Origin URL:** `https://ВАШ-ДОМЕН`
4. **Allowed Redirect URI:** `http://localhost:8765/callback` (должен совпадать с настройкой в TK).
5. **Scopes:** Vehicle Information, Vehicle Commands, Vehicle Charging Management (и Profile Information).
6. Сохраните **Client ID** и **Client Secret**.

> Fleet API тарифицируется Tesla по объёму использования. Актуальные условия и бесплатный лимит смотрите
> в developer portal. TK экономит запросы: спящий автомобиль не будится автоматически и опрашивается редко.

### Шаг 4. Регистрация приложения в регионе
Для Украины и Европы — регион `eu`:
```bat
python tools\register_partner.py --client-id ВАШ_CLIENT_ID --domain ВАШ-ДОМЕН --region eu
```
Скрипт проверит публикацию ключа, получит partner-токен и вызовет `POST /api/1/partner_accounts`.

### Шаг 5. Прокси подписи команд
```bat
python tools\generate_proxy_tls.py keys
```
Затем запустите официальный прокси одним из способов:
- **Docker Desktop:** `tools\run_proxy_docker.bat`
- **Без Docker** (нужен Go): `go install github.com/teslamotors/vehicle-command/cmd/tesla-http-proxy@latest`,
  затем `tools\run_proxy.bat`

Прокси слушает `https://localhost:4443` и доступен только с этого компьютера. Он должен работать,
когда вы отправляете команды из TK.

### Шаг 6. Виртуальный ключ в автомобиле
Откройте на телефоне с установленным приложением Tesla ссылку `https://tesla.com/_ak/ВАШ-ДОМЕН`
(или кнопка **«Добавить ключ в автомобиль»** в настройках TK) и подтвердите, находясь рядом с машиной.
После этого ключ появится в списке ключей автомобиля (Controls → Locks).

### Шаг 7. Настройки TK
Откройте TK → **Настройки разработчика** и заполните:

| Поле | Значение |
|---|---|
| Client ID / Client Secret | из шага 3 |
| Redirect URI | `http://localhost:8765/callback` |
| Регион Fleet API | Европа (для Украины) |
| Прокси подписи команд | `https://localhost:4443` |
| Сертификат прокси | `keys\tls-cert.pem` |
| Домен приложения | ваш домен |

Нажмите **CONNECT TESLA** → войдите на сайте Tesla → разрешите доступ → выберите автомобиль.

## Использование

- **LOCK / UNLOCK** — закрыть / открыть. UNLOCK всегда требует подтверждения, остальные команды — по настройке.
- **Климат** — переключатель включает/выключает кондиционирование, «−/+» и «Установить температуру» задают температуру.
- Если машина спит, TK не будит её при обновлении (чтобы не тратить заряд). Кнопка **«Разбудить»** будит вручную,
  а команды будят автомобиль автоматически.
- **Disconnect Tesla** удаляет токены с компьютера. Полностью отозвать доступ приложения можно в настройках
  безопасности аккаунта Tesla.

## Где что хранится

| Что | Где |
|---|---|
| Настройки (без секретов) | `%APPDATA%\TK\config.json` |
| Токены (зашифрованы) | `%APPDATA%\TK\tokens.bin` |
| Ключ шифрования, Client Secret | Диспетчер учётных данных Windows → `TK-TeslaKey` |
| Журнал (без токенов) | `%APPDATA%\TK\tk.log` |

## Частые ошибки

| Сообщение | Что сделать |
|---|---|
| «Автомобиль принимает только подписанные команды» | Запустите прокси (шаг 5) и укажите его в настройках |
| «Прокси подписи команд не отвечает» | Прокси не запущен или другой порт |
| «TLS-сертификат прокси не принят» | Укажите `keys\tls-cert.pem` в поле «Сертификат прокси» |
| «Виртуальный ключ не добавлен» | Шаг 6 |
| «Приложение не зарегистрировано в регионе» | Шаг 4 с правильным `--region` |
| «Аккаунт относится к другому региону» | Смените регион в настройках и переподключитесь |
| «Порт 8765 занят» | Поменяйте порт в Redirect URI и в настройках приложения на developer.tesla.com |
